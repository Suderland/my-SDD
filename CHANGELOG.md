# Changelog

## 0.1.0

Initial architecture baseline.

- Added root `AGENTS.md` engineering contract.
- Added 11 Core Skills, including adaptive requirements discovery, Spec lifecycle and testing v0.2 policy.
- Made unit, E2E and mutation testing mandatory by default for executable project-owned behavior, with explicit applicability waivers.
- Added Backend and Frontend packs.
- Added Maintainer Skills for Skill authoring, evaluation and releases.
- Added zero-dependency installer/update/status CLI.
- Added deterministic Spec status generator with `STATE.json` -> `INDEX.md`.
- Added repository validation, unit tests and GitHub Actions validation workflow.
