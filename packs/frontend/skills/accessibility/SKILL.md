# Accessibility

Prefer native semantic HTML and platform behavior before custom ARIA solutions.

## Review

- correct landmarks/headings/labels;
- full keyboard operability;
- visible and logical focus;
- accessible name/role/state for interactive controls;
- errors associated with fields and announced appropriately;
- dynamic status communicated when needed;
- sufficient contrast and non-color-only meaning;
- zoom/reflow/responsive behavior;
- media alternatives where applicable.

Automated checks are necessary but insufficient. Critical flows should include keyboard/screen-reader-informed manual verification where risk warrants it.
