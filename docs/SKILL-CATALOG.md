# Skill Catalog

## Core

| Skill | Purpose |
|---|---|
| `requirements-discovery` | Resolve consequential ambiguity after inspecting existing context. |
| `spec-lifecycle` | Create, plan, task, track and reconcile feature Specs. |
| `architecture` | System boundaries, dependency direction, DDD/Clean/Hexagonal trade-offs. |
| `software-design` | SOLID, cohesion/coupling, abstractions, patterns and maintainability. |
| `testing` | Unit, integration, contract, E2E, mutation, property-based and regression strategy. |
| `security` | Threat-aware secure design and implementation. |
| `code-quality` | Review, refactoring and maintainability gates. |
| `debugging` | Evidence-driven defect isolation and correction. |
| `verification` | Final plan-validate-execute-verify evidence loop. |
| `documentation` | Durable technical documentation tied to system truth. |
| `delivery` | Change integration, CI/CD readiness, migrations and rollback thinking. |
